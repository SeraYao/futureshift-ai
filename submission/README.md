# FutureShift AI — 提交与演示说明

FutureShift AI 根据用户问卷画像，对固定的官方职业目录计算个人适配，并展示证据、SDG 场景映射和个性化练习计划。它是辅助决策原型，不是招聘预测或职业资格认证。

## 项目和运行

- 仓库：[github.com/SeraYao/futureshift-ai](https://github.com/SeraYao/futureshift-ai)
- 应用：Python、Streamlit；直接依赖版本见 `requirements.txt`。Streamlit 1.66.0 要求 Python ≥3.11；pypdf 6.21.1 要求 Python ≥3.9。请使用 Python 3.11 或更新版本。
- 本地启动：`python3 -m streamlit run app.py --server.address 0.0.0.0 --server.port 8501`
- Replit 启动与端口发布由仓库根目录 `.replit` 配置；当前仓库未包含已部署实例或评委可访问的公网 URL。

## Replit 导入、运行和发布

1. 在 Replit 创建 App，选择从 GitHub 导入，粘贴上述仓库地址。
2. 等待 Replit 从 `requirements.txt` 安装依赖，并确认运行时 Python ≥3.11。
3. 无需 AI Secrets 即可运行问卷、官方职业推荐、SDG 映射和学习计划。
4. 若要启用可选 PDF 简历提取，在 Replit Secrets 中添加 `AI_BASE_URL`、`AI_MODEL`、`AI_API_KEY`。可选添加 `AI_TIMEOUT_SECONDS`（秒，默认 300，范围 1–3600）。请在 Secrets 中直接输入值，不要将其提交到仓库。
5. 点击 Run，使用 Webview 打开主页面。`.replit` 将 Streamlit 绑定 `0.0.0.0:8501`，并把本地 8501 端口映射到外部 HTTP 端口。
6. 如需公网演示，使用 Replit 的 Publish/Deploy 流程，检查部署环境仍使用仓库 `.replit` 的启动命令，并在部署设置中配置所需 Secrets。发布完成后，从 Replit 部署页复制实际生成的公网 URL；仓库本身无法预先提供该 URL。

建议演示使用合成画像，不需要上传真实简历。AI 提取是可选功能，不配置 AI 时其他主流程应可用。

## 当前功能状态

| Domain 1 主题 | 当前实现 | 限制 |
|---|---|---|
| 画像入口 | 问卷画像、确认步骤、可选同意后 PDF 字段提取 | 简历内容只作字段候选，用户仍需确认并自评；不从简历推断能力分 |
| 趋势证据 | BLS 美国 2025–35 快照及手动刷新；三个精确职业可展示并参与独立比较 | 不是马来西亚需求；未接入 AI 进展时间序列或技能兴衰预测 |
| 职业匹配 | 对本地 O*NET 31.0 派生目录中六个质量合格职业计算个人适配 | 固定有限目录，不代表全部职业；部分维度缺失时披露覆盖率及可比性限制 |
| 学习路径 | 根据技能/知识缺口安排四周练习，关联本地学习资源和预计时间 | 练习不是职业资格；四周不保证补齐全部能力；任务进度不改变适配分 |
| SDG | 职业和计划技能使用本地人工核验的应用场景映射 | 映射是项目分析，不是联合国背书；无合理依据时标示暂无映射 |
| 不确定性 | 展示 BLS 外部证据权重敏感性测试 | 权重是未校准的产品假设，不是未来预测；没有 AI 冲击情景模型 |

目录、排序、BLS 快照和 SDG 映射是不同证据层：职业目录是随应用提供的本地数据；画像适配由应用计算；BLS 是外部就业预测快照；SDG 是人工审查的场景分析。GitHub 技术活动演示为合成演示，不应与官方职业结果或招聘需求混为一谈。

## 技术、隐私与运行限制

- CV 文件先由 Streamlit 服务在会话中接收并在内存解析。仅在用户明确同意并点击后，脱敏且限长的文本才会发送到所配置的 AI 服务。脱敏是启发式，不能保证匿名化。项目不把 CV 写入自有磁盘或日志；AI 服务端的数据保留期限由其服务条款决定，项目未配置或验证其删除期限。
- 问卷画像、选择、计划和进度保存在各自 Streamlit 会话状态；没有应用账户数据库。不同用户不会共用同一个会话状态。趋势缓存是公开来源数据，不存个人画像。Replit 部署文件系统及缓存可能在重新部署时重置，不承诺持久化。
- 当前没有认证、账户、长期个人数据存储或已部署公共服务。公开部署前应确认 Secrets、访问范围和 AI 服务数据处理条件。
- O*NET 31.0 来自美国职业数据；BLS 为美国预测。资源链接、费用、教学语言及来源日期以应用数据和来源页面为准，外部页面内容可能变化。
