# Personalised reskilling resources

The plan is built only from positive, quality-usable skill and knowledge gaps in the selected official-derived occupation row. It sorts those gaps by weighted severity and stable questionnaire ID, then selects at most `floor(weekly_hours / 2)` areas. It does not turn missing O*NET data into zero and does not change matching scores when a task is checked.

`data/learning_resources.json` is the small manually verified catalog. Its stable resource IDs are linked to stable skill/knowledge IDs. Provider names, titles and URLs remain the source originals. Price statements distinguish free online study from optional paid print/courseware and from free participation records; no paid credential is implied. If an official source does not state the duration, the duration remains `null`/unstated. The catalog was checked on 2026-10-23.

Resources are taught in English. A Chinese or Bahasa Malaysia learning preference therefore falls back to English and says so in the interface; it does not imply that the linked course is translated. In the current six-role set, the catalog has no dedicated, verified resource for Systems Analysis, Technology Design or Speaking. The general Computers and Electronics resource is also left unassigned except for the Information Security Analyst pathway, where the Microsoft cybersecurity module is a focused fit. Those gaps retain an authored practice task and are visibly marked as lacking a matched verified resource.

Each weekly task has four different stages: establish a baseline using the linked material, practice on a small fictional case, apply to a new case, then review and record remaining study needs. The app splits the selected weekly time budget between source study and project practice; this split is an estimate. It displays the publisher's total duration separately, and does not claim the full course or occupation gap will be completed in four weeks.

Readable Markdown exports localize the task instructions and keep source titles and links. JSON exports include stable resource records, mapped IDs, language, prerequisites, costs, duration basis, verification date and catalog version. Existing `practice-v1` JSON plans are validated against the old authored-task rules, then upgraded while carrying forward completion for task IDs that still match.

The sources are maintained in the catalog and include [MIT OpenCourseWare](https://ocw.mit.edu/courses/15-053-optimization-methods-in-management-science-spring-2013/pages/syllabus/), [Microsoft Learn](https://learn.microsoft.com/en-us/training/modules/explore-analyze-data-with-python/), [OpenLearn](https://www.open.edu/openlearn/nature-environment/environmental-studies/climate-change-transitions-sustainability/content-section-0?intro=1), [U.S. EPA](https://www.epa.gov/students/lesson-plans-teacher-guides-and-online-environmental-resources-educators-water), [OpenStax](https://openstax.org/new-subjects/science-books), and [Purdue OWL](https://owl.purdue.edu/owl/).
