# FutureShift AI — 初始职业池

## 范围与状态

这是用于原型比较的多领域职业样本，不是“全球十大未来职业”，不保证就业前景、入职资格或代表马来西亚需求。不得修改正式名称制造新 AI 职位。界面可独立使用 “AI-enabled pathway” 解释性标签，不能冒充正式职位名称。

每种情景最终只推荐最高分五个职业；不足五个完整有效结果则报告不足。内部对十个候选排名，两情景比较可显示两组前五的并集并标记归属，不作为额外推荐清单。

官方职业页已核对十项名称和代码，未下载数据。在线页面可能更新，评分数值仍须核对锁定的 O*NET 31.0 CSV、字段、发布日期和许可归属。选入理由是设计判断，不是来源中的就业预测。

## 正式映射门槛

- 职业记录保留 O*NET 31.0 职业行及 Skills/Knowledge/Interests 来源。核心能力字段从问卷已询问项目中预先选择并核验，披露有限覆盖，不把未询问项目当作 0，不声称完整胜任力评估。
- GitHub 每主题记录完整查询词、纳入理由、职业任务到主题及技能/知识的映射依据、权重和版本，验证噪声及计数完整性后才能评分。
- SDG 每项保存 O*NET 角色任务引用或记录 ID、技能关系、联合国官方 target 定义来源、贡献机制、局限、审查日期与状态。表内说明仅为待验证方向；每项技能的映射也需独立审查。
- SDG 不进入总分，只用于解释、比较或主动筛选，不能用职业名称或 GitHub 热度代替贡献证据。证据不足显示待验证。
- 冻结职业池、字段、主题与规则后比较趋势更新，不为制造排名变化临时修改职业池或权重。
