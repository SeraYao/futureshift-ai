## 每个来源上线前的验证门槛

- 访问：实际 URL/数据集 ID、提供方、API/下载/人工整理方式、认证、限流、费用、失败处理及可重复获取结果。
- 许可：使用、缓存、修改、引用、展示及再分发条件；公开可读不等于可自由使用。
- 覆盖：国家/地区、语言、人群、行业与职业粒度；区分马来西亚背景与其他地域的参考信号。
- 日期：记录原始发布日期、数据所属时期、修订日期、获取日期及版本；未知项明确标记，不用获取日期替代数据日期。
- 更新：确认实际更新频率、预期滞后、查询窗口及过期阈值；保留至少两个有实质差异的真实快照以验证更新链路。
- 映射：选定统一职业与技能 ID，保存来源分类到内部分类的映射依据、覆盖率、歧义及人工审查状态；SDG 和课程也绑定这些 ID。

## 信号使用约束

新闻或研究提及频率只能作为关注度或研究活动线索，不能直接等同于就业增长、岗位需求、职业前景或技能价值。AI 能力变化需通过明确任务映射影响情景信号；就业需求必须有独立市场证据，并记录样本和地域限制。缺少证据时显示未知。

推荐需引用相关原始记录，不能只引用来源首页。职业和课程必须真实可核验；项目估计与来源事实分开保存。优先验证“一个可更新来源 → 技能/职业映射 → 信号变化 → 分数及排名变化”的最小链路；AI 与市场两类证据均需交代，若单一来源无法覆盖则补充来源。
